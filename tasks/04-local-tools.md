# 04. Подготовить Compose и Makefile

Статус: к выполнению.
Зависимости: 02, 03.
Основание: [план первой версии](README.md), [спецификация](../docs/spec.md), [правила разработки](../AGENTS.md).

## Цель

Обеспечить воспроизводимые команды разработки и отдельную локальную PostgreSQL.

## Объём работ

- Добавить deploy/docker-compose.yml с PostgreSQL 16, healthcheck, отдельным именованным volume и проектом sharetrip-notification.
- Опубликовать БД на loopback-порту 6544; не конфликтовать с share-trip.
- Добавить help, deps, tidy, fmt, lint, test, build, run, up, down и команды Goose migrate-create/status/up/down.
- Фиксировать версии CLI, устанавливать их в .tools; поддержать Windows .exe. Бинарный файл — bin/notification.
- Добавить .golangci.yml. Обычный down не должен удалять volume. Миграции не запускать автоматически вместе с приложением.

## Проверки

- [ ] Проверить Compose без вывода раскрытых секретов; выполнить up и дождаться healthy.
- [ ] Проверить make help и build; проверить доступность установленного Goose и линтера.
- [ ] Проверить остановку/повторный запуск с сохранением volume. Проверку реальных миграций выполнить в задаче 05.

## Критерий готовности

Локальная БД поднимается независимо от share-trip; команды документированы в help и исполняются.

В результате выполнения задачи указать изменённые файлы, выполненные проверки и обнаруженные ограничения.
