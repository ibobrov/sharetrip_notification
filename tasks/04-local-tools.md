## Цель

Обеспечить воспроизводимые команды разработки и отдельную локальную PostgreSQL.

## Объём работ

- Добавить deploy/docker-compose.yml с PostgreSQL 16, healthcheck, отдельным именованным volume и проектом sharetrip-notification.
- Опубликовать БД на loopback-порту 6544; не конфликтовать с share-trip.
- Добавить help, deps, tidy, fmt, lint, test, build, run, up, down и команды Goose migrate-create/status/up/down.
- Фиксировать версии CLI, устанавливать их в .tools; поддержать Windows .exe. Бинарный файл — bin/notification.
- Добавить .golangci.yml. Обычный down не должен удалять volume. Миграции не запускать автоматически вместе с приложением.
