# 02. Создать каркас Go-проекта

Статус: выполнено 15 октября 2026 года.
Зависимости: 01.
Основание: [план первой версии](README.md), [спецификация](../docs/spec.md), [правила разработки](../AGENTS.md).

## Цель

Подготовить собираемый каркас с ручной сборкой зависимостей.

## Объём работ

- Создать go.mod/go.sum и точку входа cmd/notification; использовать Go 1.26 и зависимости по AGENTS.md.
- Подготовить слои internal/api, service, domain, repository/entity, config, app и api_test по мере появления файлов.
- Зафиксировать необходимые версии Fiber v2, pgx v5, Goose v3, UUID, testify и Testcontainers. Не добавлять зависимости для доставки.
- Добавить .gitignore для .env, .tools, .reports, bin и локальных IDE-файлов; сохранить уже существующие пользовательские файлы.

## Проверки

- [x] Проверить сборку точки входа через go build ./cmd/notification.
- [x] Проверить go.mod/go.sum и отсутствие секретов и бинарных файлов в изменениях.

## Критерий готовности

Каркас собирается; бизнес-логика не находится в main. Пустые каталоги не требуют фиктивных реализаций.

В результате выполнения задачи указать изменённые файлы, выполненные проверки и обнаруженные ограничения.


## Результат

Созданы go.mod/go.sum для github.com/ibobrov/sharetrip_notification, минимальная cmd/notification/main.go и .gitignore. Закреплены шесть зависимостей из постановки. Каталоги internal будут добавляться вместе с реализациями, без фиктивных пакетов. Локальные IDE-файлы сохранены и исключены из Git.

Проверки: gofmt, go build ./cmd/notification, go vet ./..., go mod verify (all modules verified), загрузка шести закреплённых модулей и их контрольных сумм, git check-ignore и diff --check. Сборка выполнена установленным Go 1.26.0 по абсолютному пути: go отсутствует в PATH окружения. Для VCS-метаданных сборки safe.directory передан только в окружении команды, глобальные настройки Git не изменялись. Go сообщил предупреждение о недоступной записи stat cache в общий кэш модулей; команды завершились успешно.

Бинарный файл notification.exe и локальный build cache исключены из Git. Функциональных тестов ещё нет; HTTP и БД относятся к последующим задачам. Обновлены AGENTS.md и статус в tasks/README.md.
