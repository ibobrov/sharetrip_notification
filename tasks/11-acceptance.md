# 11. Проверить первую версию и описать запуск

Статус: к выполнению.
Зависимости: 04–10.
Основание: [план первой версии](README.md), [спецификация](../docs/spec.md), [правила разработки](../AGENTS.md).

## Цель

Подтвердить воспроизводимость первой версии и зафиксировать инструкции.

## Объём работ

- Обновить README: требования, .env, команды Make, POST, GET и дополнительная проверка сохранения в БД.
- Описать ожидаемые 201 для POST и 200 для GET с полным объектом в data и семантику повторных POST.
- Провести запуск с чистой локальной БД, создание уведомления и проверку сохранности после перезапуска.
- Выполнить make fmt, lint, build, test. Не заявлять прохождение недоступных проверок.
- Проверить соответствие docs/spec.md, тестов и реализации; зафиксировать оставшиеся ограничения.

## Проверки

- [ ] Прогнать все unit- и интеграционные проверки задач 03–10.
- [ ] Повторить сценарий по README: deps → up → migrate-status → migrate-up → run → POST → GET → проверка строки → перезапуск → GET с теми же данными.
- [ ] Проверить, что down/up сохраняет запись в локальном volume.
- [ ] Проверить git diff на секреты, бинарные файлы и посторонние изменения.

## Критерий готовности

Первая версия воспроизводимо запускается, проходит проверки и не требует share-trip, Keycloak или внешних каналов доставки.

В результате выполнения задачи указать изменённые файлы, выполненные проверки и обнаруженные ограничения.
