Статус: готово к приёмке; интеграционный тест сохранён для просмотра пользователя.
Зависимости: 04–10, включая 09.5.
Основание: [план первой версии](README.md), [спецификация](../docs/spec.md), [правила разработки](../AGENTS.md).

## Цель

Подтвердить воспроизводимость первой версии и зафиксировать инструкции.

## Объём работ

- Обновить README: требования, .env, команды Make, POST, GET и дополнительная проверка сохранения в БД.
- Описать ожидаемые 201 для POST и 200 для GET с прямым объектом уведомления по минимальному контракту задачи 09.5.
- Провести запуск с чистой локальной БД, создание уведомления и проверку сохранности после перезапуска.
- Выполнить make fmt, lint, build, test. Не заявлять прохождение недоступных проверок.
- Проверить соответствие docs/spec.md, тестов и реализации; зафиксировать оставшиеся ограничения.

## Проверки

- [x] Сверить фактически существующие тесты с критериями приёмки и выполнить необходимые проверки задач 03–10. Тесты конфигурации и схемы удалены; успешный make test без тестовых файлов не считается подтверждением критериев.

## Критерий готовности

Первая версия воспроизводимо запускается, проходит проверки и не требует share-trip, Keycloak или внешних каналов доставки.

В результате выполнения задачи указать изменённые файлы, выполненные проверки и обнаруженные ограничения.

## Результат

README описывает требования, настройку `.env`, команды Make, миграции, POST с ожидаемым HTTP 201, GET с ожидаемым HTTP 200, прямое чтение PostgreSQL и проверку сохранности после перезапуска приложения и Compose.

Интеграционный тест `internal/api/acceptance_test.go` запускает одноразовый PostgreSQL 16.6, применяет ту же Goose-миграцию, выполняет POST, сверяет строку напрямую, пересоздаёт HTTP-приложение и пул и выполняет GET. Тест сохранён до решения пользователя о приёмке задачи.

Локальный сценарий выполнен с ID `907567ba-0445-40a6-b1f2-ea8136051141`: POST вернул 201, GET вернул 200, объекты совпали, строка прочитана напрямую; после перезапуска приложения GET вернул 200. После `make down` и `make up` запись осталась в именованном volume.
