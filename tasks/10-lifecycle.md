## Цель

## Объём работ

- В cmd/notification собрать конфигурацию, logger, pool, repository, service и server через конструкторы.
- Слушать 127.0.0.1:8081 по умолчанию; ошибка конфигурации/БД при старте завершает процесс ненулевым кодом.
- Добавить JSON-логи в stdout: операция, результат, длительность, request ID, notification ID при наличии.
- Генерировать request ID и возвращать X-Request-Id; не логировать полный payload, пароль и DSN.
- По сигналу прекратить приём новых запросов, предоставить активным до 5 секунд и закрыть пул.

## Результат

`cmd/notification` загружает локальный `.env`, проверяет конфигурацию, создаёт пул, repository, service и Fiber router и слушает настроенный адрес. Ошибка конфигурации или подключения к PostgreSQL возвращает ненулевой код без вывода пароля или DSN.

Для каждого HTTP-запроса генерируется `X-Request-Id`. Один JSON-лог содержит operation, HTTP-код в result, duration_ms, request_id и notification_id при наличии; payload не логируется. Логгер добавляется в контекст запроса. Внутренняя ошибка обозначается безопасной категорией без текста ошибки БД.

SIGINT/SIGTERM прекращает приём новых соединений, даёт активным запросам до пяти секунд и после остановки Fiber закрывает пул. Тесты задачи удалены после приёмки пользователем.
