# 10. Собрать приложение и жизненный цикл

Статус: к выполнению.
Зависимости: 03, 08, 09.
Основание: [план первой версии](README.md), [спецификация](../docs/spec.md), [правила разработки](../AGENTS.md).

## Цель

Обеспечить диагностируемый запуск и корректную остановку процесса.

## Объём работ

- В cmd/notification собрать конфигурацию, logger, pool, repository, service и server через конструкторы.
- Слушать 127.0.0.1:8081 по умолчанию; ошибка конфигурации/БД при старте завершает процесс ненулевым кодом.
- Добавить JSON-логи в stdout: операция, результат, длительность, request ID, notification ID при наличии.
- Генерировать request ID и возвращать X-Request-Id; не логировать полный payload, пароль и DSN.
- По сигналу прекратить приём новых запросов, предоставить активным до 5 секунд и закрыть пул.

## Проверки

- [ ] Проверить ответ с X-Request-Id и связь с логом запроса.
- [ ] Проверить ненулевой код завершения при ошибке конфигурации и недоступной БД.
- [ ] Проверить остановку во время активного запроса и завершение в установленный срок.
- [ ] Проверить отсутствие чувствительных данных в логах и корректность JSON.

## Критерий готовности

Приложение запускается и останавливается с освобождением ресурсов; диагностические записи безопасны.

В результате выполнения задачи указать изменённые файлы, выполненные проверки и обнаруженные ограничения.
