# 03. Добавить конфигурацию окружения

Статус: выполнено 15 октября 2026 года.
Зависимости: 02.
Основание: [план первой версии](README.md), [спецификация](../docs/spec.md), [правила разработки](../AGENTS.md).

## Цель

Сделать настройки приложения явными и проверяемыми до запуска сервера.

## Объём работ

- Описать HTTP_HOST/HTTP_PORT (127.0.0.1/8081), DB_HOST/DB_PORT/DB_NAME (localhost/6544/sharetrip_notification), DB_SSLMODE для локального запуска.
- Требовать DB_USER и DB_PASSWORD; проверять диапазон портов и обязательные значения.
- Подготовить .env.example без настоящих секретов; предусмотреть согласование с POSTGRES_* и GOOSE_DRIVER/GOOSE_DBSTRING.
- Возвращать ошибки конфигурации вызывающему коду; не выводить пароль и полный DSN.

## Проверки

- [x] Табличные unit-тесты: defaults, явные значения, пропуск обязательного параметра, нечисловой порт и выход за диапазон.
- [x] Проверить отсутствие секретов в текстах ошибок. Изменяющие окружение тесты не запускать параллельно.

## Критерий готовности

Неверная конфигурация обнаруживается до открытия соединений; настройки покрыты тестами.

В результате выполнения задачи указать изменённые файлы, выполненные проверки и обнаруженные ограничения.


## Результат

Добавлены internal/config/env.go, internal/config/env_test.go и .env.example. config.Load возвращает типизированные HTTP/DB-настройки либо ошибку без частично заполненной конфигурации. Defaults применяются только к отсутствующим переменным. Пустые/пробельные обязательные значения, неверные порты и неизвестный SSL mode отклоняются. Пароль не обрезается; значения окружения и DSN в ошибках не выводятся.

Проверены defaults, явные значения, отсутствующие и пустые параметры, обе границы портов, ошибки формата и диапазона, SSL modes, сохранение пароля и отсутствие утечки значений. go test -count=1 -cover ./... прошёл; покрытие internal/config — 100%. go vet ./..., go build ./cmd/notification и diff --check прошли. Go 1.26.0 добавлялся в PATH только для команд проверки. При сборке сохраняется предупреждение о недоступной записи stat cache в общий кэш, код завершения — 0.

Makefile и конфигурация golangci-lint появятся в задаче 04, поэтому lint пока ограничен go vet. config.Load читает окружение процесса без загрузки файлов и сетевых вызовов; загрузка .env и вызов до инициализации пула/HTTP будут подключены в задаче 10. HTTP и БД в этой задаче не запускались.
